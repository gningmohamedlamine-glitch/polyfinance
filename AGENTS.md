# Repository instructions

## Commit messages

Use [Conventional Commits 1.0.0](https://www.conventionalcommits.org/en/v1.0.0/) for every new commit in this repository.

Use `type(scope): description`. The scope is optional. Use `feat` for a feature, `fix` for a bug fix, and a type such as `docs`, `refactor`, `test`, `build`, `ci`, or `chore` when it better describes the change. Mark breaking changes with `!` before the colon or a `BREAKING CHANGE:` footer.

Examples

- `feat(frontend): add a market movement chart`
- `fix(deploy): preserve Docker mount paths on Windows`
- `docs: require Conventional Commits`
